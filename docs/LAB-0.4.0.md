## Tooling corrections and lessons

- STATE became an explicit retrieval index; regression tests prevented accidental removal of health-condition values and multi-map identity. It shrank52,531→48,149bytes for that saved-state sample. Normal observation output remains lossless.
- Unknown-argument errors now list allowed names; a mistaken questId was locally blocked before RPC (correct argument id).
- set_schedule without assignment is inspection; setters still mutate and track intentions.
- Per-query/session shape lineage avoids repeatedly flagging a returning optional field as unseen. Changed values and new fields/types remain visible. This is not automatic evidence that a returning event is harmless.
- A duplicate attempt to complete an already completed wait was rejected locally, without replaying gameplay. The error now distinguishes closed from unknown actions.
- The tea predicate used incorrect capitalization and did not pass. Completion was explicitly reviewed against the original health evidence and recorded as manual verification. Labels are fragile: inspect exact returned values and distinguish manual review from automatic checks.
