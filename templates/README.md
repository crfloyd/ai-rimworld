# Templates

These are authoring examples, not facts or authorized game actions. Follow [startup](../docs/startup.md) to turn player intent into a campaign specification. Null preferences are unresolved; explicit delegation can settle a choice without another question. Never treat an empty intake question list as proof that the agent has reviewed the entire brief.

campaign.json stores the agreed setup and rules, optional focus/theme, sources for answers, delegation and unresolved questions. Original prompts or longer answers can live in the selected run's reference/intake/. Environment checks remain separate from player preferences. Empty DLC/mod arrays are unverified until the environment is inspected.

Movement coordinates and IDs in verification examples are arbitrary. Replace them with live evidence; a predicate must establish the actual goal.

- outcome.json: compare an evidence-linked decision with actual results; failures/unexpected or inconclusive outcomes create local lesson review candidates.
