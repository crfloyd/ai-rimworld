# Retrieve enough to decide well

This is a decision aid; match it to the current game and user rules.

## Inspect

Read the current facts, strategy and open issues; inspect freshness, origin and evidence pointers. Unknown information is not reassurance.

## Decide

Load relevant detail before major decisions. Preserve reasons, deadlines and unresolved dependencies. Keep reusable lessons scoped, provisional when appropriate, and open to contradictory evidence.

## Verify and reconsider

Retire resolved detail only with newer evidence. Check that the next agent can identify the correct next action without consuming the whole history. Compact repeated raw output before compressing important reasoning.
