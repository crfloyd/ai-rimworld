# Keep one owner and preserve uncertainty

This is a decision aid; match it to the current game and user rules.

## Inspect

Read the live catalog when owning control; otherwise use saved records. Know whether a tool pauses, changes selection or mutates game state. Confirm game/session identity before using old IDs.

## Decide

Validate arguments, issue bounded actions and retain pending request handles. Keep consequential action outcomes open. Use normal UI for unsupported targeting with a fresh screen rather than guessed coordinates.

## Verify and reconsider

Poll the actual wait handle. Inspect accepted, completed, blocked and unknown outcomes separately. Reconcile uncertain requests without replay; do not infer termination from a timeout.
